## Engineering Philosophy

<div align="center">

|                    Simple > Clever                      |                 Logs > Guesses                   |         Ship Fast            |
| :-----------------------------------------------------: | :----------------------------------------------: | :--------------------------: |
| Code should be easy to understand, change, and maintain | Good observability beats debugging by assumption | Ship, learn, improve, repeat |

|                     Design for Failure                  |                Production is Truth             |                 Build Systems              |
| :-----------------------------------------------------: | :--------------------------------------------: | :----------------------------------------: |
| Services fail. Networks fail. Systems should expect it. | Real users expose what local environments hide | Build reliable systems, not isolated demos |
